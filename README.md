## 과제 참여 방법

1. **Fork하기:** [이 저장소](https://github.com/AWS-Student-Builder-Group-at-UOS/cohort-01-assignments)를 본인 계정으로 Fork합니다.
2. **브랜치 만들기:** 개인 Fork에서 해당 회차의 브랜치(`session-02`, `session-03` 등)를 만듭니다.
3. **본인 폴더 만들기:** 회차 폴더 안에 본인 이름의 폴더(`session-NN/<본인 이름>/`)를 새로 만듭니다. 제출할 변경 사항은 본인 폴더에만 포함합니다.
4. **과제 작성하기:** 본인 폴더에 `README.md`를 만들고, [과제 템플릿](TEMPLATE.md)에 맞춰 작성합니다.
5. **이미지 첨부하기:** 본인 폴더에 `images/`를 만들고, **아키텍처 다이어그램과 실제 결과 화면을 각각 1개 이상** 넣습니다. 모든 이미지는 `![아키텍처](images/architecture.svg)`처럼 README 본문에 첨부합니다. 설정·오류·참고 이미지도 추가할 수 있으며, 파일명과 확장자는 자유입니다.
6. **PR 제출하기:** 개인 Fork의 회차 브랜치에서 이 저장소의 `main`으로 Pull Request를 엽니다. PR 템플릿에 맞춰 작성하고, **Draft가 아닌 상태**로 제출합니다.
7. **피드백 반영하기:** 리뷰 의견을 읽고 **같은 브랜치**에서 수정한 뒤 푸시합니다. 수정 사항은 기존 PR에 반영됩니다.

리뷰는 코어팀을 중심으로 진행하며, 일반 멤버도 참여할 수 있습니다. 시상은 **마감 시점의 최종 내용**으로 평가합니다. 과제 마감 후 손수빈(`ssub17`)의 최종 승인을 거쳐 코어팀이 머지합니다.

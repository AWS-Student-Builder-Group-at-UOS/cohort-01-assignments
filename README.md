## 제출 방법

아래 `02`와 `my-github-id`를 본인 회차와 GitHub ID로 바꾸세요.

1. **실습:** 회차 안내의 완료 조건·증빙·마감을 확인하고 과제를 수행합니다.
2. **작성:** 템플릿 네 항목을 `session-02/my-github-id/README.md`에 작성합니다. 같은 폴더의 `images/`에 **아키텍처 다이어그램과 실제 결과 화면을 각각 1개 이상** 넣고, 모든 이미지를 본문에 `![아키텍처](images/architecture.svg)`처럼 첨부합니다. 설정·오류·참고 이미지도 추가할 수 있으며, 파일명과 확장자는 자유입니다.
3. **브랜치 준비:** 처음 한 번 **Fork**합니다. 매 회차 내 Fork의 `main`을 **Sync fork**로 갱신하고, `session-02/my-github-id` 브랜치를 새로 만듭니다.
4. **업로드:** 새 브랜치의 저장소 첫 화면에서 **Add file → Upload files**로 준비한 `session-02` 폴더를 올리고 **Commit changes**를 누릅니다. 본인 폴더만 포함합니다.
5. **PR 제출:** **Contribute → Open pull request**를 누릅니다. 대상은 **조직 저장소의 `main`**, 출발은 **내 Fork의 새 브랜치**입니다. 제목을 `[Session 02] 홍길동 과제 제출`로 쓰고 **Create pull request**를 누릅니다.
6. **피드백:** 리뷰는 코어팀을 중심으로 진행하며, 일반 멤버도 참여할 수 있습니다. 코멘트를 읽고 **같은 브랜치**에서 수정하며, 손수빈(`ssub17`)의 최종 승인 후 코어팀이 머지합니다.

필수 항목 누락·깨진 이미지는 수정하고, 추가 실습 제안은 선택해서 반영하세요.

**Draft가 아닌 PR을 열면 제출 완료**입니다. 시상은 마감 시점의 파일로 평가합니다. [세부 기준](EVALUATION.md)

제출물과 코멘트는 공개됩니다. AWS 키·비밀번호·개인정보를 빼고, 실습 후 불필요한 리소스를 정리하세요.
